# vid-frame-analyzer
A little Python project I built to mess around with OpenCV video processing and analysis. I tested using a short MP4 (moving shapes & noise burst) generated by Claude AI, which was useful as the noise burst helped check and see if a drastic change in pixel values was
being accurately detected. The program tracks motion per frame and estimates the complexity by JPEG encoding each frame.
Graphs display those changes over time, done with matplotlib.
